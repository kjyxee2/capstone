# 03. 페르소나 에이전트 대화 웹 시각화

[02-agent-sim](../02-agent-sim/)에서 생성한 페르소나 에이전트 대화를, 웹 브라우저에서 **면세점 상황을 실시간으로 관찰하는 시뮬레이션 대시보드** 형태로 시각화한 페이지입니다.

## 실행 화면

`visualization.html` 파일 하나로 완결되며, 브라우저로 열면 바로 실행됩니다. 별도 설치나 서버가 필요 없습니다.

**GitHub Pages 배포 주소**
```
https://kjyxee2.github.io/capstone/03-simulation/visualization.html
```

## 무엇을 보여주는가

02-agent-sim에서 상용 API(Llama-3.3-70B)로 생성한 롯데면세점 상품 수령 대화를, 캐릭터가 실제로 움직이고 말하는 장면으로 재구성했습니다. 세 인물이 등장합니다.

| 인물 | 역할 | 설명 |
|------|------|------|
| 오준서 | 손님 | 일본 여행을 앞두고 인터넷면세점 구매 상품을 수령하러 온 청년 |
| 박현주 | 직원 | 픽업 데스크에서 손님을 응대하는 판매원 |
| 이은애 | 손님 | 오준서 뒷순번으로 대기 중인 손님 |

캐릭터 일러스트는 각 인물의 페르소나(나이·직업·성격)를 반영해 제작했으며, 원본은 [02-agent-sim/characters](../02-agent-sim/characters/)에 있습니다.

## 주요 기능

### 줄서기 응대 연출
단순히 세 명이 나란히 서서 번갈아 말하는 것이 아니라, 실제 면세점처럼 **순서대로 응대받는 흐름**을 구현했습니다.

1. 박현주(직원)는 카운터 뒤에 고정
2. 오준서가 대기 줄에서 카운터로 이동해 응대받음
3. 오준서의 수령이 끝나면 퇴장
4. 대기 중이던 이은애가 카운터로 이동해 응대받음

캐릭터가 화면에서 실제로 좌우로 이동하며, 상단의 대기열(QUEUE) 카운터도 응대가 끝날 때마다 줄어듭니다.

### 시뮬레이션 대시보드 UI
게임 화면이 아니라 에이전트의 상태를 관찰하는 도구처럼 구성했습니다.

- **좌측 에이전트 패널**: 각 인물의 나이·직업·거주지와 현재 상태(발화 중 / 대기 / 완료)를 상태등으로 표시
- **중앙 씬**: 밝은 면세점 배경에서 캐릭터가 말풍선으로 대화하고, 발밑에 현재 행동(ACTION) 태그가 표시됨
- **하단 콘솔 로그**: 대화가 진행될 때마다 `[시각] 턴 화자 → 행동` 형식으로 로그가 실시간 기록됨
- **상단 메타 정보**: 사용 모델, 대기열 인원, 경과 시간
- **컨트롤**: RUN / PAUSE / RESTART 버튼과 진행률 바

## 사용된 대화 데이터

시각화에 사용된 대화는 **상용 API(Llama-3.3-70B) 결과**입니다. 02-agent-sim의 비교 실험에서 로컬 3B 모델보다 역할 구분과 맥락 유지가 안정적이었던 상용 API 쪽 결과를 채택했습니다.

각 대사에는 화자, 발화 내용, 행동(스마트폰 확인 / 시스템 조회 / 시계 확인 등)이 함께 담겨 있어, 대화와 액션이 동시에 표현됩니다.

## 기술 구성

- 순수 HTML / CSS / JavaScript 단일 파일 (외부 라이브러리 없음)
- 캐릭터 이미지는 base64로 파일 내부에 포함되어 별도 이미지 파일 불필요
- CSS transition으로 캐릭터 이동·강조 애니메이션 처리
- JavaScript로 턴 진행, 타이핑 효과, 상태 관리, 로그 기록 제어
