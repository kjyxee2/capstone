# 공군호텔 상권 가상인간 방문 시뮬레이션 — 요약

## 무엇을 했나

서울시 상권분석서비스의 **공군호텔 상권(상권코드 3110815)**을 대상으로, 2026년 1분기 실제 유동인구 분포를 정답표로 두고 Nemotron-Personas-Korea 가상인간의 페르소나 기반 방문 시뮬레이션 결과와 비교했다.

논문용 엄격 버전에서는 **원본 데이터에서 확인되지 않은 브랜드명, 개별 점포 좌표, 임의 400m 상권 영역을 모두 제거**했다.

## 실험 설정

| 항목 | 값 |
|---|---|
| 실제 유동인구 데이터 | 길단위인구-상권, 2026 Q1 |
| 대상 상권 | 공군호텔 / 3110815 |
| 실제 총 유동인구 | 1,172,513명 |
| 에이전트 풀 | 100,000명 |
| 시뮬레이션 방문자 | 30,671명 |
| 방문 비율 | 30.7% |
| 방문 판단 | 페르소나 기반 규칙 모형 |
| 업종 데이터 | 점포-상권, 2025 Q4 |

**주의:** 방문확률과 시간대 배정은 실제 관측 확률이 아니라 연구자가 설정한 시뮬레이션 규칙이다.

## 핵심 결과

| 검증 항목 | MAE (%p) | 상관계수 |
|---|---:|---:|
| 성별 | 1.64 | r = 1.000* |
| 연령대 | 4.48 | r = 0.745 |
| 시간대 | 8.20 | r = -0.610 |

\* 성별은 비교값이 2개뿐이므로 상관계수는 참고용.

- 성별과 연령대는 상대적으로 실제 분포와 가까웠다.
- 시간대는 재현에 실패했다. 실제는 **00-06시 26.3%**가 가장 높았지만 시뮬레이션은 **17-21시 25.5%**가 가장 높았다.
- 전체 평균 MAE는 **4.78%p**다.

## LLM 샘플 검증 정정

현재 노트북 실행 결과:

- 샘플: 100명
- 규칙기반 YES: 8명
- LLM YES: 4명
- 일치율: **90.0%**

90건의 일치 중 89건이 `NO-NO`이므로, 90% 일치율만으로 두 방법이 동일한 판단 성능을 가진다고 해석하지 않는다.

## 실제 업종 데이터 정정

서울시 상권분석서비스 **점포-상권 2025 Q4**에서 본 시뮬레이터가 유지하는 5개 업종의 존재와 점포 수를 다시 확인했다.

| 업종 | 전체 | 일반 | 프랜차이즈 |
|---|---:|---:|---:|
| 한식음식점 | 27 | 24 | 3 |
| 슈퍼마켓 | 12 | 9 | 3 |
| 커피-음료 | 9 | 7 | 2 |
| 편의점 | 9 | 3 | 6 |
| 여관 | 5 | 5 | 0 |

기존 문서의 **93 / 27 / 23 / 18 / 5** 값은 현재 사용 중인 `점포-상권` 2025 Q4 원본 기준과 일치하지 않아 폐기했다.

또한 이 5개를 공군호텔 상권 전체의 "상위 5개 업종"이라고 표현하지 않는다. **기존 시뮬레이션 후보 중 실제 존재가 확인된 5개 업종**이다.

## HTML 엄격 버전

- 롯데 계열 등 임의 브랜드명 삭제
- 데이터에서 확인되지 않은 업종 삭제
- 임의 업종 좌표/마커 삭제
- 반경 400m 상권 원 삭제
- 개별 점포가 실제 위치에 있는 것처럼 보이는 표현 삭제
- 업종별 연령/키워드 임의 선호 가중치 삭제
- 방문 이후 업종 선택은 **실제 점포 수 비례**로 변경
- 결과는 "실제 매장 방문"이 아니라 **"업종 선택 시뮬레이션"**으로 표현

점포 데이터에는 개별 상호명·주소·위경도가 없으므로 현재 버전은 이를 만들어내지 않는다.

## 해석 원칙

논문에서는 아래를 구분한다.

- **관측값:** 유동인구 분포, 업종 존재, 점포 수
- **모델 가정:** 방문확률 규칙, 시간대 배정, 점포 수 비례 업종 선택
- **현재 확인 불가:** 개별 점포 위치, 공식 상권 경계, 실제 개인별 방문 업종

또한 유동인구는 **2026 Q1**, 점포는 **2025 Q4**이므로 두 자료의 기준 시점이 다름을 명시한다.
