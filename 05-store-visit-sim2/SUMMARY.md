# 공군호텔 상권 가상인간 방문 시뮬레이션 — 요약

## 무엇을 했나
서울시 상권분석서비스 데이터에서 **공군호텔 상권**(서울 영등포구, 대방역 인근)을 선택하여 실제 유동인구 분포를 정답표로 삼고, **Nemotron-Personas-Korea 가상인간 에이전트**가 페르소나(나이·성별·취미)만으로 이 상권을 방문할지 예측한 결과가 실제와 얼마나 일치하는지 검증했다.

## 실험 설정

| 항목 | 값 |
|---|---|
| 대상 상권 | 공군호텔 (실제 총 유동인구 1,172,513명) |
| 에이전트 풀 | 100,000명 (Nemotron 100만 명 중 샘플링) |
| 방문 판단 | 정답표 미참고, 순수 페르소나 기반 규칙 + LLM(Qwen2.5-3B) 샘플 검증 |
| 채워진 방문자 | 30,671명 (수락률 30.7%) |
| 매장 | 5종 (한식음식점·커피-음료·슈퍼마켓·여관·편의점 — 실제 업종명, 실제 존재 확인) |

## 핵심 결과

| 검증 항목 | MAE (%p) | 상관계수 |
|---|---|---|
| 성별 | 1.64 | r = 1.000 |
| 연령대 | 4.48 | r = 0.745 |
| 시간대 | 8.20 | r = −0.610 |

- **성별·연령대는 상당히 잘 재현됨.** 페르소나에 명시된 정보(나이·성별)일수록 예측력이 높았다.
- **시간대는 재현 실패.** 실제로는 새벽(00-06시)이 26.3%로 가장 높았지만, 시뮬레이션은 저녁(17-21시)이 25.5%로 가장 높아 정반대 패턴을 보였다. 페르소나 텍스트에 시간대 정보가 없다는 근본적 한계.
- **LLM(3B) vs 규칙기반 일치율 93%** — 소규모 로컬 모델도 규칙 기반과 유사하게 판단했으나, 둘 다 이 상권의 이례적 새벽 패턴은 예측하지 못했다.

## 매장 선정의 정확성 확보
서울시 상권분석서비스(점포-상권배후지) 실데이터로 이 상권에 실제 존재하는 업종을 전수 확인했다. 초기에는 8개 업종을 가상의 롯데 계열사 브랜드명으로 라벨링했으나, 이 중 4개(영화관·면세점·테마파크·백화점)는 이 소규모 근린상권에 실제로 존재하지 않았다. 정확성을 위해 이를 전면 수정하여, **실제 존재가 확인된 상위 5개 업종을 실제 업종명 그대로** (한식음식점 93개·커피-음료 27개·슈퍼마켓 23개·여관 18개·편의점 5개) 사용하도록 지도·시뮬레이션·인터랙티브 도구를 재구성했다.
