# 공군호텔 상권 가상인간 방문 시뮬레이션

서울시 상권분석서비스의 **길단위인구-상권** 데이터를 기준으로 `공군호텔` 상권(상권코드 `3110815`)을 선택하고, 실제 유동인구 분포를 정답표(ground truth)로 두어 Nemotron-Personas-Korea 가상인간의 페르소나 기반 방문 시뮬레이션이 실제 분포를 어느 정도 재현하는지 검증한 프로젝트입니다.

이 문서는 논문·보고서 사용을 고려해, **원본 데이터에서 확인되지 않은 브랜드명·개별 점포 위치·임의 상권 경계는 사실처럼 제시하지 않는 것**을 원칙으로 정리한 버전입니다.

## 파일 구성

```text
gonggun_paper_strict_complete/
├── README.md
├── SUMMARY.md
├── index.html
├── store_map.html
├── gonggun_store_evidence_2025Q4.csv
└── CHANGES_paper_strict.txt
```

- `index.html`: 페르소나 기반 방문 여부 판정 + 검증된 업종 현황 + 업종 선택 누적 시뮬레이션
- `store_map.html`: 이름은 기존 호환성을 위해 유지했지만, **임의 지도/마커를 제거한 업종 근거표**
- `gonggun_store_evidence_2025Q4.csv`: 공군호텔 상권의 5개 검증 대상 업종 점포 수 근거
- `CHANGES_paper_strict.txt`: 논문용 엄격 버전 수정 내역

## 1. 데이터와 기준 시점

본 프로젝트에는 서로 다른 두 공공데이터 시점이 사용됩니다.

| 용도 | 데이터 | 기준 시점 |
|---|---|---|
| 실제 유동인구 정답표 | 서울시 상권분석서비스(길단위인구-상권) | **2026년 1분기** |
| 업종 존재 및 점포 수 확인 | 서울시 상권분석서비스(점포-상권) | **2025년 4분기** |

두 자료는 인접 분기이지만 **동일 시점 데이터는 아닙니다.** 따라서 논문에서는 유동인구 검증과 업종 현황 확인의 기준 시점이 다르다는 점을 명시해야 합니다.

### 대상 상권

- 상권코드: **3110815**
- 상권명: **공군호텔**
- 상권구분: **골목상권**
- 2026년 1분기 총 유동인구: **1,172,513명**

개별 점포의 주소·위경도나 공식 상권 Polygon은 현재 제공받은 두 집계 데이터만으로 확인할 수 없으므로, 본 엄격 버전에서는 임의 좌표와 임의 반경을 사용하지 않습니다.

## 2. 가상인간 에이전트

Nemotron-Personas-Korea 데이터셋에서 **100,000명**을 무작위 샘플링해 에이전트 풀로 사용했습니다. 각 에이전트는 나이·성별·직업·거주지와 페르소나 텍스트(취미·생활 특성 등)를 포함합니다.

### 방문 여부 판단

방문 여부 판단에는 실제 유동인구 분포를 직접 입력하지 않고, 에이전트의 속성과 페르소나를 이용한 규칙 기반 확률을 사용했습니다.

- 기본 방문 확률: 30%
- 연령대별 연구자 설정 가중치
- 페르소나 텍스트의 활동성 관련 키워드 가감

**주의:** 이 `visit_prob`는 관측된 실제 방문확률이 아니라, 연구자가 설정한 **휴리스틱(규칙 기반) 시뮬레이션 확률**입니다. 따라서 논문에서는 실제 행동확률로 표현하면 안 됩니다.

각 에이전트에 대해 해당 확률로 베르누이 시행을 수행한 결과:

- 에이전트 풀: **100,000명**
- 기대 방문자 수: **30,666명**
- 실제 시뮬레이션 방문자 수: **30,671명**
- 방문 비율: **30.7%**

### 시간대 배정

페르소나 데이터에 실제 활동 시각이 직접 제공되지 않기 때문에 연령대별 시간대 성향을 연구자가 가정하여 확률적으로 배정했습니다.

이 역시 **실측 행동 데이터가 아닌 모델 가정**이며, 실제 유동인구 시간대 분포는 시간대 배정 규칙에 사용하지 않았습니다.

## 3. 실제 유동인구 분포

2026년 1분기 공군호텔 상권의 길단위인구 데이터를 정답표로 사용했습니다.

- 성별: 남 **48.3%** / 여 **51.7%**
- 연령대: 60대+ **21.4%**로 가장 높은 비중
- 시간대: 00-06시 **26.3%**로 가장 높은 비중

00-06시 비중이 높은 이유 자체는 현재 길단위인구 데이터만으로 확인할 수 없습니다. 따라서 특정 시설이나 생활패턴을 원인으로 단정하지 않습니다.

## 4. 시뮬레이션 vs 실제 분포

### 성별

| 성별 | 실제(%) | 시뮬레이션(%) | 오차(%p) |
|---|---:|---:|---:|
| 남 | 48.3 | 49.9 | 1.6 |
| 여 | 51.7 | 50.1 | 1.6 |
| **MAE** | | | **1.64** |

성별 상관계수는 `r = 1.000`이지만 비교 항목이 2개뿐이므로 참고용으로만 보는 것이 적절합니다.

### 연령대

| 연령대 | 실제(%) | 시뮬레이션(%) | 오차(%p) |
|---|---:|---:|---:|
| 10대 | 11.4 | 1.6 | 9.8 |
| 20대 | 17.9 | 22.6 | 4.7 |
| 30대 | 18.0 | 22.0 | 4.0 |
| 40대 | 15.7 | 19.9 | 4.2 |
| 50대 | 15.5 | 16.2 | 0.6 |
| 60대+ | 21.4 | 17.8 | 3.6 |
| **MAE** | | | **4.48** |

- 상관계수: **r = 0.745**

10대 비중이 크게 낮은 것은 Nemotron 샘플의 연령 구성과 관련된 구조적 한계로 해석할 수 있습니다.

### 시간대

| 시간대 | 실제(%) | 시뮬레이션(%) | 오차(%p) |
|---|---:|---:|---:|
| 00-06 | 26.3 | 4.6 | 21.6 |
| 06-11 | 20.9 | 17.9 | 3.0 |
| 11-14 | 12.0 | 19.3 | 7.4 |
| 14-17 | 11.8 | 19.5 | 7.7 |
| 17-21 | 16.2 | 25.5 | 9.3 |

실제 데이터는 00-06시가 가장 높지만 시뮬레이션은 17-21시가 가장 높아 시간대 패턴 재현에는 실패했습니다.

**전체 평균 MAE: 4.78%p**

## 5. LLM 샘플 검증

에이전트 100명을 샘플링하여 Qwen2.5-3B-Instruct의 방문 YES/NO 판단과 규칙 기반 판단(`visit_prob >= 0.5`)을 비교했습니다.

현재 노트북 실행 결과는 다음과 같습니다.

| 항목 | 값 |
|---|---:|
| 샘플 수 | 100 |
| 규칙기반 YES | 8 |
| LLM YES | 4 |
| 규칙기반-LLM 일치율 | **90.0%** |

혼동행렬:

| | LLM NO | LLM YES |
|---|---:|---:|
| 규칙기반 NO | 89 | 3 |
| 규칙기반 YES | 7 | 1 |

90% 일치율의 대부분은 두 방식이 모두 `NO`라고 판단한 89건에서 발생했습니다. 따라서 **90%라는 숫자만으로 두 방식이 높은 수준으로 동일하다고 결론 내리면 안 됩니다.** 특히 YES 사례에 대한 일치는 제한적입니다.

## 6. 업종 데이터 검증 및 정정

초기 버전에서는 실제 데이터로 확인되지 않은 롯데 계열 브랜드명과 존재하지 않는 업종을 시뮬레이션 화면에 사용한 문제가 있었습니다. 논문용 엄격 버전에서는 해당 요소를 모두 제거했습니다.

업종 존재와 점포 수는 **서울시 상권분석서비스(점포-상권), 2025년 4분기, 상권코드 3110815**에서 다시 확인했습니다.

본 시뮬레이터에서 유지하는 5개 업종의 전체 점포 수는 다음과 같습니다.

| 업종 | 전체 점포 수 | 일반 점포 수 (`stor_co`) | 프랜차이즈 점포 수 (`frc_stor_co`) |
|---|---:|---:|---:|
| 한식음식점 | **27** | 24 | 3 |
| 슈퍼마켓 | **12** | 9 | 3 |
| 커피-음료 | **9** | 7 | 2 |
| 편의점 | **9** | 3 | 6 |
| 여관 | **5** | 5 | 0 |

여기서 전체 점포 수는 데이터의 `similr_induty_stor_co` 값을 사용하며, 이 5개 업종에서는 `일반 점포 수 + 프랜차이즈 점포 수`와 일치합니다.

**이 5개를 '공군호텔 상권 전체 업종 중 상위 5개'라고 표현하지 않습니다.** 현재 버전의 목적은 기존 시뮬레이션에 사용하던 업종 중 원본 데이터에서 실제 존재가 확인된 5개만 유지하는 것입니다.

### 제거한 요소

- `롯데마트`, `롯데호텔`, `롯데백화점` 등 임의 브랜드명
- 공군호텔 상권 데이터에서 확인되지 않은 영화관·면세점·테마파크·백화점
- 업종별 임의 대표 좌표
- 대방역 좌표를 상권 중심이라고 간주한 표현
- 반경 400m를 공식 상권 영역처럼 표시한 원
- 개별 점포가 실제 위치에 존재하는 것처럼 보이는 지도 마커

현재 제공된 점포 데이터는 **업종별 집계 데이터**이므로 개별 상호명·주소·위경도는 확인할 수 없습니다.

## 7. 엄격 버전의 업종 선택 방식

기존 코드에는 "20대는 카페 선호", "60대는 슈퍼마켓 선호"와 같은 연구자 임의 가중치와 페르소나 키워드 가중치가 들어 있었습니다.

논문용 HTML에서는 이 가중치를 제거했습니다.

방문 판정 후 업종을 하나 선택할 때는, 검증된 5개 업종의 **2025년 4분기 전체 점포 수 비율**만 사용합니다.

총 62개를 기준으로 한 선택 가중치는:

| 업종 | 점포 수 | 선택 비중 |
|---|---:|---:|
| 한식음식점 | 27 | 43.5% |
| 슈퍼마켓 | 12 | 19.4% |
| 커피-음료 | 9 | 14.5% |
| 편의점 | 9 | 14.5% |
| 여관 | 5 | 8.1% |

이 결과는 **실제 소비자의 업종 방문 비율이 아닙니다.** 실제 업종 공급 구성에 비례하여 선택한 시뮬레이션 값입니다.

따라서 화면에서도 "실제 매장 방문"이 아니라 **"업종 선택"**으로 표현합니다.

## 8. 웹 시뮬레이터 표시 원칙

`index.html`과 `store_map.html`은 논문용 엄격 원칙에 맞게 수정했습니다.

- 실제 개별 점포 지도 마커 없음
- 임의 상권 원 없음
- 존재가 검증된 업종명과 점포 수만 표시
- 개별 점포 좌표가 없다는 사실을 화면에 명시
- 방문 여부는 기존 페르소나 기반 규칙 모형
- 방문 이후 업종 선택은 실제 점포 수 비례
- 업종 선택 결과는 실제 관측 방문 기록으로 표현하지 않음

`store_map.html`은 파일명 호환성을 위해 이름은 유지하지만, 현재는 **정적 지도 대신 검증된 업종 근거표**를 제공합니다.

## 9. 결론

### 재현 성능

- **성별:** MAE 1.64%p
- **연령대:** MAE 4.48%p, r = 0.745
- **시간대:** MAE 8.20%p, r = -0.610

성별과 연령대는 상대적으로 실제 분포와 가까웠지만, 시간대는 실제 새벽 유동 패턴을 재현하지 못했습니다.

이 결과는 페르소나에 직접 포함된 나이·성별과 달리, **특정 상권을 언제 방문하는지에 대한 정보는 페르소나만으로 충분히 추론하기 어렵다**는 한계를 보여줍니다.

### 논문에서 반드시 구분해야 할 것

1. 실제 데이터  
   - 2026 Q1 유동인구 분포
   - 2025 Q4 업종 존재 및 점포 수

2. 연구자 설정/시뮬레이션  
   - 방문확률 산정 규칙
   - 시간대 배정 규칙
   - 점포 수 비례 업종 선택

3. 현재 데이터로 확인할 수 없는 것  
   - 개별 점포명과 위치
   - 공식 상권 경계
   - 실제 개인별 업종 방문 기록
   - 실제 방문의 인과적 이유

이 세 범주를 분리해 기술해야 분석 결과를 실제 관측값보다 과장하지 않을 수 있습니다.
