# 2단계 실험: 상권정보 프롬프트 기반 LLM 재시뮬레이션 결과

## 실험 목적
1단계(규칙 기반 + 소형 LLM 샘플 검증)에 이어, **상권정보를 명시적으로 제공한 대형 LLM(120B)** 이 페르소나 개인별로 "이 상권을 앞으로 30일간 몇 번, 언제 방문할지"를 직접 판단하도록 하여, 실제 유동인구 분포와의 정합성을 재검증했다.

## 실험 설계

### 데이터 전처리: 10대 제외 및 재정규화
Nemotron-Personas-Korea 데이터셋은 19세 이상 성인만 포함하고 있어, 실제 정답표의 10대 비중(11.4%)과 비교가 원천적으로 불가능하다. 이에 10대 카테고리를 정답표·시뮬레이션 양측에서 제외하고 나머지 5개 연령대(20대-60대+) 비율을 100%로 재정규화했다. 이 조정만으로 연령대 MAE가 **4.49%p에서 2.78-2.87%p로 약 37-38% 개선**되어, 비교 불가능한 카테고리가 오차를 구조적으로 부풀리고 있었음을 확인했다.

### 프롬프트 설계
상권정보(업종 구성·운영시간·시간대별 이용 특성)를 요약한 컨텍스트와 개별 페르소나(나이·성별·직업·성향)를 함께 제공하고, "향후 30일간 총 방문 횟수(0~30)·주요 방문 시간대·주요 방문 요일"을 JSON으로 응답하도록 설계했다.

### 모델 선정 과정
- **1차 시도(Qwen2.5-3B, 로컬)**: 예/아니오 이분법 질문에서 100% "예"로 수렴, 0~30 숫자 질문에서도 대부분 15(범위 중앙값)로 수렴. 개인차를 전혀 반영하지 못하는 한계를 확인.
- **2차 시도(Groq API, openai/gpt-oss-120b)**: 추론형 대형 모델로 전환. 초기 프롬프트는 토큰 소모가 과다(1명당 약 2,300토큰)하여 Groq 무료 티어 일일 한도(20만 토큰)로 300명 완주가 불가능했음. 프롬프트를 압축(상권정보 요약, 페르소나 텍스트 절삭, 출력 형식 예시 명시)하여 1명당 약 844토큰까지 절감했다.

### 최종 실행
샘플 180명(10대 제외, Nemotron 100만 명 풀에서 무작위 추출)을 목표로 gpt-oss-120b 판정을 실행했다. Groq API 일일 토큰 한도(20만 토큰) 도달로 146명 시점에서 중단되었으며, 판단 형식 오류로 인한 실패는 0건이었다(146명 전원 유효 응답).

### 방법론적 검증: 상권정보 원문 보존 확인
초기 실행에서는 토큰 절약을 위해 상권정보를 한 문장으로 요약하는 과정에서 "새벽·오전 이용" 관련 서술이 누락되는 오류가 있었다. 이 오류가 시간대 예측 실패의 원인일 가능성을 배제하기 위해, **원본 상권정보 JSON을 요약·재작성 없이 그대로 프롬프트에 포함**하여 재실행했다(위 표는 이 재실행 결과다). 원본에는 "편의점·숙박·일부 식당의 24시간 운영과 공원 아침 운동으로 새벽·오전 이용도 뒷받침됨"이라는 문장이 명시적으로 포함되어 있었음에도, 시뮬레이션 결과에서 00-06시 응답은 여전히 0건이었다. 이로써 시간대 예측의 실패가 프롬프트 요약 과정의 정보 손실 때문이 아니라, **모델이 제공된 배경정보 중 일부(저녁·평일 관련 서술)에 편중되어 반응하고 다른 정보(새벽 이용 가능성)는 결과에 반영하지 않는 근본적인 경향**에서 비롯됨을 확인했다.

## 해석

### 상권정보 제공이 오히려 정확도를 떨어뜨린 이유
시간대 시뮬레이션이 17-21시(저녁)에 55.6%, 06-11시(오전)에 38.2%로 쏠려 두 시간대가 전체의 93.7%를 차지했다. 이는 상권정보 원문에 포함된 "출근 전·퇴근 후 생활 이용이 중심이라 오전과 저녁에 활동이 이어지고"라는 서술을 모델이 그대로 답습한 결과로 해석된다. 원문에는 바로 이어서 "새벽·오전 이용도 뒷받침됨"이라는 문장이 명시되어 있었음에도, 00-06시 응답은 146명 전원 중 단 한 건도 나오지 않았다. 이는 모델이 상권정보 전체를 균형 있게 반영하는 것이 아니라, **서술상 먼저 언급되거나 더 구체적으로 묘사된 정보(오전·저녁)에 편중되어 반응하고, 상대적으로 짧게 언급된 정보(새벽 이용 가능성)는 결과에 실질적으로 반영하지 않는 경향**을 시사한다.

### 모델 크기와 정확도의 비선형 관계
Qwen2.5-3B(로컬)에서 openai/gpt-oss-120b(API, 추론형 대형 모델)로 모델 규모를 40배 이상 키웠음에도, 최종 정합성은 오히려 악화되었다(전체 평균 MAE 4.78%p → 12.30%p). 이는 "더 큰 모델이 더 정확한 시뮬레이션을 만든다"는 가정이 항상 성립하지 않으며, **입력 프롬프트에 담긴 배경정보의 구성 자체가 결과를 좌우하는 더 지배적인 요인**일 수 있음을 보여준다. 특히 방문 시간대처럼 실제 데이터에 이례적 패턴(새벽 유동인구 최다)이 존재하는 지표는, 상권을 일반적으로 서술하는 배경 정보가 모델의 판단을 그 서술 쪽으로 편향시킬 수 있다.

### 순수 페르소나 기반 접근의 상대적 우위
정답표(상권의 실제 통계)를 전혀 참고하지 않고 페르소나의 나이·취미만으로 확률을 산출한 1단계 규칙 기반 방식이, 상권 배경정보까지 원문 그대로 제공받은 2단계 대형 LLM 판단보다 실제 분포에 더 가까운 결과를 냈다는 점은 역설적이지만 중요한 발견이다. 이는 "이 상권이 어떤 곳인지"에 대한 서술형 배경정보보다, "이 사람이 어떤 사람인지"에 대한 개인 정보가 방문 패턴 예측에 더 유효한 신호일 수 있음을 시사한다.

## 3단계: 하이브리드 접근 (개선안)

### 설계
2단계 결과를 항목별로 분해해 보면, LLM(120B)은 **방문 횟수**(1~30회, 개인차를 반영한 연속값 산출)에서는 페르소나별로 유의미하게 다른 값을 냈으나, **시간대·요일**(범주형 선택)에서는 상권정보 문장을 그대로 재사용하는 경향을 보여 실제 분포보다 균등 무작위 배정보다도 큰 오차를 냈다(시간대 MAE 18.88%p, 균등 무작위 배정 시 예상 MAE 4.62%p보다 4배 이상 높음). 이에 따라 각 구성요소가 상대적으로 강점을 보인 방법을 조합하는 하이브리드 방식을 설계했다.

- **방문 횟수**: 2단계 LLM(120B) 결과를 그대로 사용
- **시간대**: LLM 판단을 배제하고, 1단계에서 사용한 연령대별 시간대 확률표(정답표 미참고, 상식 기반 사전 설계)로 재배정
- **요일**: LLM 판단을 배제하고, 달력 구조(평일 5일:주말 2일)에 기반한 사전확률로 재배정

두 재배정 모두 정답표를 참고하지 않고 사전에 설계된 규칙을 적용했으므로, 정답을 보고 끼워맞추는 것이 아니라 1·2단계와 동일한 검증 조건을 유지했다.

| 항목 | 1단계 (순수 규칙기반) | 2단계 (LLM+상권정보) | 3단계 (하이브리드) |

## 결론
공군호텔 상권은 대방역 인근이라는 입지 특성상 일반적인 근린상권과 다른 이례적 시간대 패턴(00-06시 새벽 유동인구가 전체 시간대 중 최다인 26.3%)을 보인다. 이 정보가 상권정보에 명시적으로 포함되어 있었음에도(원문 그대로 프롬프트에 반영, 요약 과정의 정보 손실 없음을 별도로 검증함), 시도한 두 모델(3B, 120B) 모두 이 패턴을 결과에 반영하지 못했으며, 특히 시간대·요일 판단은 균등 무작위 배정보다도 낮은 정확도를 보였다. 이는 프롬프트에 이례적 패턴을 아무리 명시적으로 적어 넣어도 모델이 이를 실제로 판단에 반영한다는 보장이 없으며, 모델 규모를 키우는 것만으로는 이 한계가 해소되지 않는다는 것을 실증적으로 보여준다.

다만 LLM이 모든 항목에서 무력했던 것은 아니다. 개인별 방문 횟수처럼 상권정보에 구체적 힌트가 없는 연속값 산출 과제에서는 페르소나별로 유의미하게 다른 값을 내며 개인차 반영력을 보였다. 이 관찰을 바탕으로 방문 횟수는 LLM 판단을, 시간대·요일은 정답표를 참고하지 않은 규칙 기반 배정을 결합한 하이브리드 방식을 구성한 결과, 전체 평균 MAE가 12.30%p에서 4.99%p로 개선되어 1단계 순수 규칙 기반 수준을 회복했다. 이는 LLM 기반 상권 시뮬레이션을 설계할 때, 모델에 모든 판단을 일임하기보다 **각 하위 과제(연속값 추정 vs 범주형 분류, 개인 정보 기반 판단 vs 공통 배경정보 기반 판단)의 특성에 따라 LLM과 규칙 기반 방법을 선택적으로 결합하는 것**이 단일 방법을 확대 적용하는 것보다 실제 데이터 정합성 확보에 더 효과적일 수 있음을 시사한다.

## 연구의 한계

### 1·3단계 규칙 기반 확률표의 근거
1단계 방문 확률표와 3단계 시간대 재배정에 사용한 연령대별 확률표(예: 20대의 저녁 시간대 선호 32%, 60대+의 오전 시간대 선호 28%)는 통계청 자료나 선행 연구를 인용한 것이 아니라, "젊은 층은 저녁에 활동적이고 고령층은 아침 활동을 선호한다"는 일반적 통념에 기반해 연구자가 사전에 설정한 값이다. 확률표 설계 시점에 공군호텔 상권의 실제 정답표(특히 00-06시 새벽 유동인구가 전체 시간대 중 최다라는 이례적 패턴)를 참고하지 않았으므로 정답을 보고 역산한 것은 아니나, 이 가정 자체가 일반적으로 타당한지는 별도로 검증되지 않았다. 따라서 1단계와 3단계가 2단계보다 낮은 오차를 기록한 것은 "이 방법론이 본질적으로 우수함"을 뜻하기보다, "연구자가 설정한 상식적 가정이 이 특정 상권의 실제 분포와 우연히 상당 부분 부합했음"으로 해석하는 것이 더 정확하다. 요일 배정에 사용한 5:2(평일:주말) 비율은 달력의 객관적 구조에 근거하므로 상대적으로 근거가 명확하나, 시간대 확률표는 이러한 객관적 근거가 부족하다는 한계가 뚜렷하다.

### 표본 크기 및 API 제약
2·3단계 실험은 목표했던 180명 중 Groq API의 일일 토큰 사용 한도(20만 토큰) 도달로 146명(81%)까지만 완료되었다. 이는 판정 실패가 아니라 API 제약에 따른 조기 종료이며, 146명 자체는 형식 오류 없이 모두 유효한 응답이었으나, 180명 전체를 완료했을 경우와 결과가 다를 가능성을 배제할 수 없다.

### 이 연구의 핵심 기여 범위
본 연구의 기여는 "어떤 방법이 가장 낮은 오차를 기록했는가"보다, ① 대형 LLM(120B)에게 상권 배경정보와 개인 페르소나를 함께 제공했을 때 개인차가 소거되고 배경정보 텍스트가 그대로 답습되는 현상을 재현 가능한 형태로 확인한 것, ② 이 현상이 프롬프트 압축 오류가 아니라 원문 그대로 제공한 경우에도 재현됨을 검증한 것, ③ 같은 LLM이라도 과제 유형(연속값 추정 vs 범주형 분류)에 따라 성능 차이를 보인다는 것을 확인한 것, ④ 이에 기반한 하이브리드 설계가 실제로 개선 효과를 냄을 실증한 것에 있다. 오차 수치 자체의 절대적 우열보다 이러한 정성적·구조적 발견에 무게를 두어 해석해야 한다.
